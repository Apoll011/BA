# BA

Sítio do atelier de detalhe automóvel BA. Next.js (App Router), React, TypeScript e Tailwind CSS. Textos em português europeu.

## Correr localmente

```bash
npm install
npm run dev
```

O servidor de desenvolvimento escuta em `0.0.0.0:4317`.

Abra [http://127.0.0.1:4317](http://127.0.0.1:4317).

## Conteúdo de exemplo

Morada, telefone, horário, email e Instagram vivem em `src/lib/site.ts` e devem ser substituídos antes de publicar o atelier a sério.

A fotografia do hero está em `public/bg.png`. Se esse ficheiro não vier no clone, `npm run dev` reconstitui-o a partir de `hero/bg.b64.*`.
